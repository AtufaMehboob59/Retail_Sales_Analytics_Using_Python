#  Retail Sales Analytics using Python

## Project Overview

This project analyzes retail sales data using Python to understand business performance and customer purchasing patterns. It includes exploratory data analysis (EDA), KPI calculations, and visualizations to identify sales trends and generate business insights.

## Objectives

- Clean and preprocess retail sales data.
- Perform exploratory data analysis (EDA).
- Calculate key business metrics (KPIs).
- Analyze product and category performance.
- Visualize sales trends using charts.
- Create a dashboard for business insights.

## Dataset

The dataset contains retail transaction records, including:
 1  Transaction_ID           
 2  Timestamp       
 3  Category             
 4  Product                
 5  Quantity                
 6  Unit Price              
 7  Discount (%)            
 8  Sales Amount           
 9  City                  
 10 Payment Mode

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab


## Key Performance Indicators (KPIs)

- Total Revenue
- Total Orders

- Total Items Sold


## Visualizations

- Category-wise Sales Analysis
- Monthly Sales Trend
- Top Selling Products
